# joehoshina.netlify.app

Personal portfolio. Plain HTML/CSS/JS in a single `index.html`, no build step.

- `logos/`, `media/`: images and the SkyMedia demo video referenced by the page
- `netlify.toml`: publishes the repo root as-is

Preview locally with `python3 -m http.server 4173`, then open http://localhost:4173.

The previous React/Vite version is tagged `v1-react`.
