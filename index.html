Support Agent

AI · Product

An AI assistant that knows when to hand off

32%fewer chats reaching live agents
19test suites gating every release
125cases in a model-graded eval harness

A Claude-powered Node service, the browser widget, and a live handoff to Salesforce agents, built end to end. In credit reporting the hard part is refusing to guess: guardrails route anything outside the knowledge base to a human, and the knowledge base refreshes from a doc support edits, so answers get fixed the same day without a deploy.

Details
  • A second model grades every answer in the eval harness. A missed escalation fails the build; an unnecessary one only warns.
  • Hardened the public API: SSNs and card numbers redacted before storage, scrypt-hashed passwords, signed sessions, rate limiting, non-root Docker on PostgreSQL.
  • A/B-tested a tone rewrite before shipping it: average reply length fell from 79 to 47 words with zero change to escalation behavior.
  • Claude API

SkyMedia

Full-stack · AI

An ad manager for in-flight entertainment and connectivity (IFEC), built as a proof of concept

Used by
Panasonic's internal operators and airline operators
Airline tenants
United AirlinesAmerican AirlinesDelta Air Lines
3in-flight entertainment vendors behind one delivery interface
8failure types, each with its own recovery rule
1-clickrollback to the last known-good version

Operators use it to run ads across seatback and connectivity screens: define audiences, build campaigns, then push them to the fleet. My part was getting content onto aircraft that are only intermittently online. Each vendor's system sits behind one adapter interface, deliveries respect an airline's window (always, ground-only, or scheduled), and a failed update retries, opens an incident, then rolls back to the last good version and closes once the aircraft confirms.

Details
  • Resumable delivery. Pause, resume, and failure recovery for aircraft on intermittent links, so an interrupted transfer continues instead of restarting. The prototype shipped in the revamped dashboard's first release.
  • Delivery reporting. Impressions aggregated across flights, so operators see what a campaign actually delivered instead of inferring it.
  • Natural-language search. Ask for a number or setting and land on the right view instead of digging through menus.
  • AI compliance check on uploaded ad assets before they can reach a screen.
